Queen's Domain Map
==================

An interactive 3D map of the whole world of Queen's Domain: every item pickup, secret wall, boss, NPC, save point,
teleporter, locked door and inscription, ticked off from your own save file. Unofficial and fan-made; not affiliated
with the game's developers or publisher.

You need the game installed. The map is built on your PC from your own copy of it: no game content is part of this
download.


Starting it
-----------

1. Put QueensDomainMap.exe in a folder of its own (Documents\QueensDomainMap, for example).
2. Double-click it. Windows may show "Windows protected your PC" the first time, because the program is not signed:
   choose "More info", then "Run anyway".
3. Your browser opens the map. On the first start it asks to build the map: this reads the game's files, takes about
   a minute and about 600 MB of disk space in a "data" folder beside the program. Nothing in the game folder is changed.

The program finds a Steam install by itself. If it does not find the game, choose "Game folder..." and pick the folder
that holds QueensDomain.exe.

While the map runs, its icon sits next to the clock (it may be behind the small arrow there). Click it to open the map
again, right-click it to quit. Starting the program a second time just opens the map.


Good to know
------------

- Everything stays on your PC. The program serves the page to your own browser only (http://localhost:8765) and
  reads your save files without ever writing to them.
- After a game update the map says that the game's files have changed and offers to rebuild. You can also do that at
  any time under View > Map program > Rebuild the map. Found marks are kept.
- Save slots are found by themselves. If yours are somewhere else, or you want to see only one account's saves:
  Save box > "Game and save folders...".
- Found marks you set by hand are stored in your browser. View > Progress > Export makes a backup.
- The "data" folder holds content taken from your copy of the game. It is for your own use; please do not share it.
- To remove everything: quit the program, then delete its folder.
